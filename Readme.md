EDA Modular Workflow (Python)

A reusable and modular template for performing quick and efficient Exploratory Data Analysis (EDA) on any dataset using Python.

This workflow helps analysts quickly:

Import & inspect data

Check data health

Clean structure & missing values

Analyse numerical & categorical columns

Create basic visualizations

Generate insights faster


This is designed as a plug-and-play framework to speed up EDA for real-world projects.
